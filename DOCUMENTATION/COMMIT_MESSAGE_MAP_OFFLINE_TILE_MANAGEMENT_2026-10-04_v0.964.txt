BL_Add persistent map switching and offline tile lifecycle v0.964

Date: 2026-10-04

Summary:
- Kept map provider/token configuration persistent in the Android backend and made map/region JSON writes safer.
- Added direct in-map switching between OSM, Mapbox presets/custom style and Custom XYZ sources.
- Defined Auto as offline/cache-first, Offline as cache-only and Online as provider-first with cache fallback.
- Added offline region update, full reload, tile-only deletion and region removal with shared-tile protection.
- Added cache size/tile status to offline region management and synchronized map settings across views.
- Added Map API v3 region-maintenance endpoints and disabled browser tile caching so backend data-mode policy remains authoritative.
- Bumped Android/WebUI version to 0.964 and Android versionCode to 37.
