Important compatibility note:
- A fresh installation can use this release key immediately.
- An in-place Android update is possible only when the already installed APK is signed with the same certificate and has a lower versionCode.
- If an older installed PotensicProxy_TAF APK was signed with a different debug/release key, the new key cannot replace that signer. The old private key would be required for a seamless update; otherwise the old app must be uninstalled once before installing the first APK signed with this fixed key.
