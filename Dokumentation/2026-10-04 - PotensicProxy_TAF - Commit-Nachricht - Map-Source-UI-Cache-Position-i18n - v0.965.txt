BL_Implement shared map UI and separated tile caches
Date: 2026-10-04

Summary:
- Implement the v0.965 Map Source UI refactor with compact token/status information and accessible info popovers.
- Separate temporary browsing tiles from deliberately downloaded offline areas, add temporary-cache inspection/clear APIs, and migrate the v0.964 combined cache layout.
- Add manual cartographic current-position handling with strict separation from drone telemetry, Home/RTH and flight-control data.
- Reuse shared map tile/source/zoom controls across Cockpit, Mission Planning and the Map tab; keep the Map-data quick selector limited to the large Cockpit map and synchronize changes without page reloads.
- Add English, German and Chinese i18n strings for all new map UI elements and update software/Map API versions to 0.965 / v4.
- Add implementation documentation, delivery note and patch.
- Optional "Save as offline area" remains documented as an open extension as permitted by the change order.
