BL_Improve landing controls and telemetry readability
Date: 2026-10-07

Summary:
- Made all four landing-assist sliders reliably self-centering by using pointer capture and neutralizing each axis on pointer release, cancellation, lost capture, keyboard release, and focus loss.
- Added minus and plus single-step buttons to Throttle, Yaw, Pitch, and Roll. Each press sends a short +/-10 RC-unit pulse for 160 ms and then automatically returns the axis to zero.
- Added persistent telemetry-bar font-size settings for improved readability on large displays.
- Added a System / Display settings panel with direct numeric input, slider control, and reset to the 10 px default.
- Added a configurable telemetry font-size range from 9 px to 24 px and kept the setting in LocalStorage.
- Updated the WebUI version to 0.974 and the Android application to versionName 0.974 / versionCode 47.
- Added PDF and DOCX project documentation and release artifacts for this change.
- Kept the existing project structure and the PotensicProxy_TAF root folder unchanged.
