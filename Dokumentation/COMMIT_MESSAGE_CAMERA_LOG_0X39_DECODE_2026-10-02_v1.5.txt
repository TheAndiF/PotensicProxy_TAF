BS_Decode ATOM camera 0x39 diagnostic logs
Date: 2026-10-02

Summary:
- Parse asynchronous camera command 0x39 using the PotensicPro CameraLogData layout: source byte, uint16-LE payload length, and exact source payload.
- Decode validated ATOM Linux camera-log payloads with XOR 0x55 and escape control bytes so each camera record remains one Live System Log entry.
- Keep Gimbal camera logs binary and show a bounded hexadecimal preview instead of feeding binary data through a text decoder.
- Keep LiteOS camera logs raw until a source=1 capture validates its encoding.
- Reject truncated 0x39 payload declarations and report unexpected trailing bytes.
- Document the implementation evidence from PotensicPro and the 2026-10-02 USB capture.
