# Potensic Atom 2 — تدقيق الخصوصية: بيانات مرسلة دون علم المستخدم (Arabic / العربية)

> **البرنامج الثابت المحلل:** cam_atom2_v8.12.11 (2025-09-19) — `main_app` (10MB, aarch64 ELF)
> **مكتبة RemoteID:** `libridtrans.so` (ASTM F3411 / OpenDroneID)
> **المعالج:** HiSilicon Hi3519DV500

---

## 1. RemoteID — بث مستمر عبر BLE/WiFi (الأكثر توغلاً)

عبر `libridtrans.so` (بروتوكول ASTM F3411 / OpenDroneID)، تبث الطائرة بدون طيار البيانات التالية باستمرار عبر BLE وWiFi:

| البيانات | دالة API |
|------|-------------|
| **الرقم التسلسلي** (UASID = `[MFR CODE][SERIAL]`) | `RIDTRANS_SetBasicID` |
| **موقع GPS في الوقت الفعلي** (خط العرض، خط الطول، الارتفاع) | `RIDTRANS_SetLocation` |
| **السرعة الأفقية/العمودية** | `RIDTRANS_SetLocation` |
| **اتجاه الطيران** | `RIDTRANS_SetLocation` |
| **الارتفاع البارومتري + الجيوديسي** | `RIDTRANS_SetLocation` |
| **دقة الموقع الأفقي/العمودي/السرعة** | `RIDTRANS_SetLocation` |
| **موقع الطيار** (Operator Location) | `RIDTRANS_SetSystem` |
| **فئة وتصنيف الاتحاد الأوروبي** للطائرة | `RIDTRANS_SetSystem` |
| **معرف المشغل** | `RIDTRANS_SetOperatorID` |
| **نص حر** (Self ID) | `RIDTRANS_SetSelfID` |
| **بيانات المصادقة** | `RIDTRANS_SetAuth` |
| **الطابع الزمني** | `RIDTRNAS_SetTime` |

**أي شخص** يملك جهاز استقبال BLE/WiFi ضمن نطاق ~1 كم يمكنه قراءة كل هذه البيانات في الوقت الفعلي. هذا **مقصود بالتصميم** (لوائح الاتحاد الأوروبي/إدارة الطيران الفيدرالية)، لكن المستخدمين قد لا يكونون على دراية كاملة بحجم البيانات المبثوثة.

## 2. بيانات EXIF/XMP الوصفية في الصور ومقاطع الفيديو

كل ملف صورة أو فيديو يحتوي على بيانات وصفية مضمنة (فضاء أسماء XMP `http://www.ipotensic.com/drone/1.0/`):

| الحقل | المحتوى |
|-------|---------|
| `GPSLatitude` / `GPSLongitude` | الموقع الدقيق |
| `GPSAltitude` | الارتفاع |
| `AbsoluteAltitude` / `RelativeAltitude` | الارتفاع المطلق والنسبي |
| `GimbalPitchDegree` / `GimbalRollDegree` / `GimbalYawDegree` | اتجاه الكاميرا |
| `FlightPitchDegree` / `FlightRollDegree` / `FlightYawDegree` | اتجاه الطائرة |
| `FlightXSpeed` / `FlightYSpeed` / `FlightZSpeed` | السرعة ثلاثية الأبعاد |
| `CameraSerialNumber` / `BodySerialNumber` | الأرقام التسلسلية |
| `Make` / `Model` | معرفات الأجهزة |
| `ISOSpeed` / `ShutterSpeedValue` / `FNumber` | إعدادات الكاميرا |

هذه البيانات **مضمنة في الملفات** — إذا شاركت صورة أو مقطع فيديو، فإن كل هذه البيانات تذهب معها.

## 3. مسار "Potensic MetaData" الخاص في مقاطع فيديو MP4

تحتوي تسجيلات فيديو MP4 على **مسار بيانات خاص** (`Create private data track`) مع إدخالات `UserDefAtom` — تدفق قياس عن بعد كامل مشفر داخل ملف الفيديو (GPS، الوضعية، السرعة، إلخ. لكل إطار).

## 4. نبضات القلب إلى تطبيق الهاتف — تدفق بيانات مستمر

ترسل `camera_heartbeat` باستمرار إلى تطبيق الهاتف المتصل:
- وضع التشغيل
- حالة بطاقة SD
- حالة الوسائط
- حالة WiFi Direct
- الحالة المركبة
- وضع الوسائط النشط

## 5. مصادقة الهاتف

تقوم الطائرة **بتحديد ومصادقة** الهاتف المتصل:
- `is_cellphone_id_authenticated` — تتحقق مما إذا كان الهاتف مصرحاً له
- `cellphone id authenticated: %s` — تسجل معرف الهاتف
- الرمز المميز مخزن في `/data/config/token`

## 6. مناطق حظر الطيران — مفروضة بصمت

نظام مناطق حظر الطيران (`deepsea_nfz`):
- يحمل مناطق الحظر من خوادم Potensic (عبر تطبيق الهاتف)
- يخزنها في `/data/no_fly_zone/` (بصيغ دائرية + مضلعة)
- وحدة التحكم بالطيران **ترفض الطيران** في هذه المناطق
- لا يمكن للمستخدم **إزالتها** بدون صلاحيات الجذر

## ما لا يتم فعله (إيجابي)

- الطائرة **لا تتصل مباشرة بالإنترنت** — كل الاتصالات تمر عبر تطبيق الهاتف
- لا يوجد إرسال مباشر للقياس عن بعد إلى السحابة من الطائرة
- لا يوجد سلوك "اتصال تلقائي بالمصدر" مستقل

## ملخص المخاطر

| المخاطر | الخطورة | تحكم المستخدم |
|------|----------|-------------|
| بث RemoteID للموقع/الرقم التسلسلي باستمرار | **عالية** | لا يوجد (لا يمكن تعطيله بدون صلاحيات الجذر) |
| GPS/الرقم التسلسلي مضمن في الصور المشاركة | **متوسطة** | إزالة بيانات EXIF قبل المشاركة |
| مسار القياس عن بعد في مقاطع الفيديو | **متوسطة** | لا توجد طريقة بسيطة للإزالة |
| مناطق حظر الطيران مفروضة من الخادم | **متوسطة** | لا يوجد بدون صلاحيات الجذر |
| مصادقة الهاتف | **منخفضة** | طبيعي لعملية الاقتران |
