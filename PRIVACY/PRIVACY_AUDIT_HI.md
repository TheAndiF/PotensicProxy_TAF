# Potensic Atom 2 — गोपनीयता ऑडिट: उपयोगकर्ता की जानकारी के बिना भेजा गया डेटा (Hindi / हिन्दी)

> **विश्लेषित फर्मवेयर:** cam_atom2_v8.12.11 (2025-09-19) — `main_app` (10MB, aarch64 ELF)
> **RemoteID लाइब्रेरी:** `libridtrans.so` (ASTM F3411 / OpenDroneID)

## 1. RemoteID — निरंतर BLE/WiFi प्रसारण (सबसे अधिक आक्रामक)

`libridtrans.so` (ASTM F3411 / OpenDroneID प्रोटोकॉल) के माध्यम से, ड्रोन BLE और WiFi पर निम्नलिखित डेटा लगातार प्रसारित करता है:

| डेटा | API फंक्शन |
|------|-------------|
| **सीरियल नंबर** (UASID = `[MFR CODE][SERIAL]`) | `RIDTRANS_SetBasicID` |
| **रियल-टाइम GPS स्थिति** (अक्षांश, देशांतर, ऊंचाई) | `RIDTRANS_SetLocation` |
| **क्षैतिज/ऊर्ध्वाधर गति** | `RIDTRANS_SetLocation` |
| **उड़ान दिशा** | `RIDTRANS_SetLocation` |
| **बैरोमेट्रिक + जियोडेटिक ऊंचाई** | `RIDTRANS_SetLocation` |
| **क्षैतिज/ऊर्ध्वाधर/गति सटीकता** | `RIDTRANS_SetLocation` |
| **पायलट की स्थिति** (Operator Location) | `RIDTRANS_SetSystem` |
| **EU श्रेणी + वर्ग** ड्रोन का | `RIDTRANS_SetSystem` |
| **ऑपरेटर ID** | `RIDTRANS_SetOperatorID` |
| **मुक्त पाठ** (Self ID) | `RIDTRANS_SetSelfID` |
| **प्रमाणीकरण डेटा** | `RIDTRANS_SetAuth` |
| **टाइमस्टैम्प** | `RIDTRNAS_SetTime` |

~1km रेंज के भीतर BLE/WiFi रिसीवर वाला **कोई भी व्यक्ति** इस सभी डेटा को रियल टाइम में पढ़ सकता है। यह **डिज़ाइन के अनुसार** है (EU/FAA नियम), लेकिन उपयोगकर्ता प्रसारित डेटा की सीमा के बारे में पूरी तरह जागरूक नहीं हो सकते हैं।

## 2. फोटो और वीडियो में EXIF/XMP मेटाडेटा

प्रत्येक फोटो और वीडियो फ़ाइल में एम्बेडेड मेटाडेटा होता है (XMP नेमस्पेस `http://www.ipotensic.com/drone/1.0/`):

| फ़ील्ड | सामग्री |
|-------|---------|
| `GPSLatitude` / `GPSLongitude` | सटीक स्थिति |
| `GPSAltitude` | ऊंचाई |
| `AbsoluteAltitude` / `RelativeAltitude` | निरपेक्ष और सापेक्ष ऊंचाई |
| `GimbalPitchDegree` / `GimbalRollDegree` / `GimbalYawDegree` | कैमरा अभिविन्यास |
| `FlightPitchDegree` / `FlightRollDegree` / `FlightYawDegree` | ड्रोन अभिविन्यास |
| `FlightXSpeed` / `FlightYSpeed` / `FlightZSpeed` | 3D गति |
| `CameraSerialNumber` / `BodySerialNumber` | सीरियल नंबर |
| `Make` / `Model` | हार्डवेयर पहचानकर्ता |
| `ISOSpeed` / `ShutterSpeedValue` / `FNumber` | कैमरा सेटिंग्स |

यह डेटा **फ़ाइलों में एम्बेडेड** है — यदि आप कोई फोटो या वीडियो साझा करते हैं, तो यह सब उसके साथ जाता है।

## 3. MP4 वीडियो में निजी "Potensic MetaData" ट्रैक

MP4 वीडियो रिकॉर्डिंग में एक **निजी डेटा ट्रैक** (`Create private data track`) होता है जिसमें `UserDefAtom` प्रविष्टियां होती हैं — वीडियो फ़ाइल के भीतर एन्कोडेड एक पूर्ण टेलीमेट्री स्ट्रीम (GPS, एटीट्यूड, गति, आदि प्रति-फ्रेम आधार पर)।

## 4. फोन ऐप को हार्टबीट — निरंतर डेटा स्ट्रीम

`camera_heartbeat` लगातार कनेक्टेड फोन ऐप को भेजता है:
- ऑपरेटिंग मोड
- SD कार्ड स्थिति
- मीडिया स्थिति
- WiFi Direct स्थिति
- समग्र स्थिति
- सक्रिय मीडिया मोड

## 5. फोन प्रमाणीकरण

ड्रोन कनेक्टेड फोन को **पहचानता और प्रमाणित करता** है:
- `is_cellphone_id_authenticated` — जांचता है कि फोन अधिकृत है या नहीं
- `cellphone id authenticated: %s` — फोन की ID लॉग करता है
- टोकन `/data/config/token` में संग्रहीत

## 6. नो-फ्लाई ज़ोन — चुपचाप लागू

NFZ सिस्टम (`deepsea_nfz`):
- Potensic सर्वरों से प्रतिबंध क्षेत्र डाउनलोड करता है (फोन ऐप के माध्यम से)
- उन्हें `/data/no_fly_zone/` में संग्रहीत करता है (वृत्त + बहुभुज प्रारूप)
- फ्लाइट कंट्रोलर इन क्षेत्रों में **उड़ान से इनकार करता** है
- उपयोगकर्ता रूट एक्सेस के बिना **इन्हें हटा नहीं सकता**

## क्या नहीं किया जाता (सकारात्मक)

- ड्रोन **सीधे इंटरनेट से कनेक्ट नहीं होता** — सभी संचार फोन ऐप के माध्यम से होता है
- ड्रोन से कोई सीधी क्लाउड टेलीमेट्री नहीं
- कोई स्वायत्त "phone home" व्यवहार नहीं
