# Potensic Atom 2 — Аудит конфиденциальности: данные, отправляемые без ведома пользователя (Russian / Русский)

> **Проанализированная прошивка:** cam_atom2_v8.12.11 (2025-09-19) — `main_app` (10MB, aarch64 ELF)
> **Библиотека RemoteID:** `libridtrans.so` (ASTM F3411 / OpenDroneID)
> **SoC:** HiSilicon Hi3519DV500

---

## 1. RemoteID — Непрерывная трансляция по BLE/WiFi (наиболее инвазивная)

Через `libridtrans.so` (протокол ASTM F3411 / OpenDroneID) дрон непрерывно транслирует следующие данные по BLE и WiFi:

| Данные | Функция API |
|--------|-------------|
| **Серийный номер** (UASID = `[MFR CODE][SERIAL]`) | `RIDTRANS_SetBasicID` |
| **GPS-позиция в реальном времени** (широта, долгота, высота) | `RIDTRANS_SetLocation` |
| **Горизонтальная/вертикальная скорость** | `RIDTRANS_SetLocation` |
| **Направление полёта** | `RIDTRANS_SetLocation` |
| **Барометрическая + геодезическая высота** | `RIDTRANS_SetLocation` |
| **Точность горизонтальная/вертикальная/скорости** | `RIDTRANS_SetLocation` |
| **Позиция пилота** (Operator Location) | `RIDTRANS_SetSystem` |
| **Категория и класс ЕС** дрона | `RIDTRANS_SetSystem` |
| **Идентификатор оператора** | `RIDTRANS_SetOperatorID` |
| **Произвольный текст** (Self ID) | `RIDTRANS_SetSelfID` |
| **Данные аутентификации** | `RIDTRANS_SetAuth` |
| **Временная метка** | `RIDTRNAS_SetTime` |

**Любой**, имеющий BLE/WiFi-приёмник в радиусе ~1 км, может считывать все эти данные в реальном времени. Это сделано **намеренно** (нормативы ЕС/FAA), но пользователи могут не полностью осознавать объём транслируемых данных.

## 2. Метаданные EXIF/XMP в фотографиях и видео

Каждый файл фотографии и видео содержит встроенные метаданные (пространство имён XMP `http://www.ipotensic.com/drone/1.0/`):

| Поле | Содержимое |
|------|------------|
| `GPSLatitude` / `GPSLongitude` | Точные координаты |
| `GPSAltitude` | Высота |
| `AbsoluteAltitude` / `RelativeAltitude` | Абсолютная и относительная высоты |
| `GimbalPitchDegree` / `GimbalRollDegree` / `GimbalYawDegree` | Ориентация камеры |
| `FlightPitchDegree` / `FlightRollDegree` / `FlightYawDegree` | Ориентация дрона |
| `FlightXSpeed` / `FlightYSpeed` / `FlightZSpeed` | 3D-скорость |
| `CameraSerialNumber` / `BodySerialNumber` | Серийные номера |
| `Make` / `Model` | Идентификаторы оборудования |
| `ISOSpeed` / `ShutterSpeedValue` / `FNumber` | Настройки камеры |

Эти данные **встроены в файлы** — если вы делитесь фотографией или видео, все эти данные передаются вместе с ними.

## 3. Приватный трек "Potensic MetaData" в видео MP4

Видеозаписи в формате MP4 содержат **приватный трек данных** (`Create private data track`) с записями `UserDefAtom` — полный поток телеметрии, закодированный внутри видеофайла (GPS, ориентация, скорость и т.д. покадрово).

## 4. Heartbeat к приложению на телефоне — непрерывный поток данных

`camera_heartbeat` непрерывно отправляет в подключённое приложение на телефоне:
- Режим работы
- Статус SD-карты
- Статус медиа
- Статус WiFi Direct
- Составной статус
- Активный режим медиа

## 5. Аутентификация телефона

Дрон **идентифицирует и аутентифицирует** подключённый телефон:
- `is_cellphone_id_authenticated` — проверяет, авторизован ли телефон
- `cellphone id authenticated: %s` — логирует идентификатор телефона
- Токен хранится в `/data/config/token`

## 6. Бесполётные зоны — Скрытое принудительное применение

Система NFZ (`deepsea_nfz`):
- Загружает зоны ограничений с серверов Potensic (через приложение на телефоне)
- Сохраняет их в `/data/no_fly_zone/` (форматы: окружность + полигон)
- Полётный контроллер **отказывается летать** в этих зонах
- Пользователь **не может их удалить** без root-доступа

## Что НЕ делается (положительные моменты)

- Дрон **не подключается напрямую к Интернету** — вся связь идёт через приложение на телефоне
- Нет прямой облачной телеметрии с дрона
- Нет автономного поведения типа "phone home"

## Сводка рисков

| Риск | Степень | Контроль пользователя |
|------|---------|----------------------|
| RemoteID непрерывно транслирует позицию/серийный номер | **Высокая** | Отсутствует (нельзя отключить без root) |
| GPS/серийный номер встроены в публикуемые фотографии | **Средняя** | Удалить EXIF перед публикацией |
| Трек телеметрии в видео | **Средняя** | Нет простого способа удаления |
| NFZ принудительно применяются сервером | **Средняя** | Отсутствует без root |
| Аутентификация телефона | **Низкая** | Нормально для сопряжения |
